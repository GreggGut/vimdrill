# vimdrill

A 12-week course that teaches Vim in Neovim: 60 short lessons, each with a lesson card, a hands-on
drill scored by keystrokes against par, and quiz questions. `vimdrill --mix` generates fresh practice
rounds from the lessons you've done.

**Work in progress.** Setup and usage are being reworked so the course runs on its own, with or without
Claude Code. A full guide follows.

Requirements: Python 3.10+, Neovim 0.11+, Linux, macOS or WSL.
